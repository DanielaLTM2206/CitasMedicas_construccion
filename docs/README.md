# Documentación y Artefactos de Ingeniería de Software

En este directorio se centralizan los artefactos formales del ciclo de vida del software según el plan de construcción:

- `srs/`: Especificación de Requisitos de Software bajo el estándar IEEE 830 (15 Requisitos Funcionales y No Funcionales).
- `bpmn/`: Modelado del flujo de proceso de negocio en notación BPMN (Bizagi Modeler) y matriz de actividades.
- `uml/`: Diagramas de Casos de Uso del sistema, plantillas textuales y diagramas de interacción/actividades.
- `rtm/`: Matriz de Trazabilidad de Requisitos (RTM) vinculando necesidades, RFs y entregables técnicos.
- `database/`: Modelos conceptual, lógico y físico de datos (Diagramas E-R y diccionario de datos).
