# Componentes de Interfaz de Usuario (UI)

Componentes modulares y reutilizables para el prototipo:

- Barra de navegación superior con conmutador rápido de roles y perfil de usuario activo.
- Tarjetas de médicos con modalidades (Presencial / Teleconsulta) y tarifas.
- Temporizador interactivo de bloqueo preventivo de turnos (cuenta regresiva de 5 minutos).
- Calendario interactivo con selectores de semana/día y badges de estado de turnos (Libre, Reservado, En Proceso).
- Diálogos modales accesibles para confirmación de cancelación, bajas lógicas y carga de documentos PDF.
- Sistema de notificaciones toast flotantes con tiempos de desvanecimiento suave.
