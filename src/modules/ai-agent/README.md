# Agente Conversacional IA - SaludBot (RF-011, RF-012)

- **RF-011**: Asistente de lenguaje natural que interpreta intenciones de reagendamiento, verifica reglas de antelación mínima, consulta disponibilidad real de turnos y ofrece 2 a 3 opciones mediante llamadas a funciones estructuradas (tool calling).
- **Aislamiento de seguridad**: El asistente opera invocando funciones internas validadas, sin acceso a escrituras directas a la base de datos ni respuestas médicas no autorizadas.
- **Interfaz**: Chat conversacional con visualización de la tarjeta de cita actual, sugerencias rápidas ("pills") y confirmación en un clic.
