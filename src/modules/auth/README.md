# Módulo de Autenticación y Cuentas (RF-001, RF-008, RF-014)

- **RF-001**: Registro de Paciente en 2 pasos (datos personales, validación de cédula y confirmación por código vía correo electrónico).
- **RF-008**: Inicio de sesión seguro con selector de roles (Paciente, Médico, Administrador), bloqueo de acceso para médicos en estado 'Pendiente' o 'Dada de baja'.
- **RF-014**: Recuperación de contraseña mediante enlace temporal de un solo uso con caducidad de 15 minutos vía correo electrónico.
