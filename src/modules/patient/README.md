# Módulo del Paciente (RF-002, RF-009)

- **RF-002**: Agendamiento de citas de medicina general (selección de modalidad Presencial en Consultorio o Consulta Virtual, selección de médico y horario disponible).
- **RF-009**: Cancelación de citas agendadas con ingreso de motivo obligatorio, confirmación explícita, validación de tiempo límite de antelación y liberación inmediata del turno.
- **Historial y Estado**: Pestaña 'Mis Citas' con filtros por estado ('Programadas', 'Canceladas', 'Completadas').
