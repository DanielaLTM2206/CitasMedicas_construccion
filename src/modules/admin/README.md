# Módulo de Administración (RF-006, RF-012, RF-013)

- **RF-006**: Auditoría de solicitudes médicas con visualización de la licencia digital en PDF, opción de aprobación ('Activo'), subsanación o rechazo definitivo por fraude.
- **RF-012**: Configuración de reglas y parámetros del Agente de IA Conversacional (horas mínimas de antelación para reagendamientos).
- **RF-013**: Directorio global de usuarios y baja lógica de cuentas (inactivación justificada con motivo, validación de citas futuras pendientes y preservación de historial).
