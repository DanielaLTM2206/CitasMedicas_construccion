# Vistas del Médico General
- `registro-medico.html`: Solicitud de registro con subida de archivo PDF de licencia ACESS/Senescyt.
- `agenda-laboral.html`: Parametrización de turnos, descansos, buffer y duración de citas.
- `control-asistencia.html`: Agenda del día para marcar asistencia en tiempo real ('Atendida' o 'Inasistencia').
- `reportes.html`: Dashboard de productividad, tasas de asistencia, filtros y descarga de informes PDF/CSV.
